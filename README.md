# Optical Encoders Project

Design, build, and characterise an absolute optical encoder (5-bit Gray code, transmissive disk) and a quadrature encoder for measuring motor shaft position and speed on Arduino Uno hardware.

## Repository structure

- `absolute_encoder/` — absolute encoder sketch placeholder and notes
- `quadrature_encoder/` — quadrature encoder sketch placeholder and notes
- `shared/` — shared sketch placeholder and shared-module notes
